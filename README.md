## 📌 Project Overview

**NexusDash** is a modern, interactive, and fully responsive dashboard web application. This project was developed to fulfill **Task 6 (Advanced) - Modern Web Application Dashboard** for the Frontend Developer Internship Program at **Auspify Technologies**.

The application simulates a real-world business management dashboard, allowing users to monitor analytics, manage customers, and track transactions seamlessly.

## 🌐 Live Demo
Experience the application live here: 
👉 **[https://kusnadi34.github.io/task-6_Web-Applications/](https://kusnadi34.github.io/task-6_Web-Applications/)**

## 🚀 Key Features

*   **Full CRUD Functionality:** Create, Read, Update, and Delete both Customers and Transactions data.
*   **Undo Action:** A sleek Toast Notification allows users to undo data deletion within 5 seconds.
*   **Data Persistence:** Uses browser `localStorage` to ensure data is not lost upon page refresh.
*   **Data Visualization:** Interactive revenue charts using `Recharts` library.
*   **Multi-Theme & Dark/Light Mode:** Customizable UI with 6 different color palettes (Purple, Ocean, Forest, Sunset, Cyberpunk, Rose Gold).
*   **User Authentication (Simulation):** Login/Register modal overlay.
*   **Profile Management:** Features image upload (Base64 conversion) for user avatars.
*   **Fully Responsive:** Optimized for Desktop, Tablet, and Mobile viewing.

## 🛠️ Technologies Used
*   **Framework:** React.js (via Vite)
*   **Styling:** Vanilla CSS3 (Custom Variables, Flexbox, CSS Grid)
*   **Icons:** Lucide React
*   **Charts:** Recharts
*   **Deployment:** GitHub Pages (via GitHub Actions)
